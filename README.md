# About The Project

MindBalance is an interactive educational platform designed to improve children's financial awareness through an engaging experience that combines a digital game concept with a smart saving box prototype.

The project transforms financial concepts into daily practices through challenges, saving goals tracking, and interactive learning.


# Problem

Most financial education methods for children focus mainly on theoretical content without providing interactive experiences that help children apply these concepts and build healthy financial habits.


# Proposed Solution

MindBalance provides a playful learning experience where children complete challenges, earn rewards, and connect their achievements with a smart saving box that helps them track their financial goals.

The concept also includes an AI-powered financial advisor that can provide personalized guidance and challenges based on each child's progress.


# Project Components

## Interactive Game Design

The game introduces children to financial awareness concepts through different stages and challenges, helping them learn saving and decision-making skills in an enjoyable way.

## Smart Saving Box Prototype

A hardware prototype was developed using Arduino components to simulate a smart saving box.

The prototype includes:
- LCD screen to display saving goals, current amount, and progress percentage.
- Button to simulate saving actions.
- NeoPixel ring to provide feedback when achieving goals.


## 3D Design

The smart saving box model was designed using 3D modeling tools and connected with the hardware concept to represent the final product vision.


# Data Usage

The project uses user-generated data such as:
- Financial goals entered by the child.
- Saving progress.
- Challenge results.
- Interaction data generated through the game and smart saving box.

This data can be analyzed to provide a personalized learning experience and recommendations.
